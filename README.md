# edi-download

Downloads for [EasyDiffraction](https://github.com/enhantica/edi): the desktop installers' online component repositories,
the Python package index and the release feed. The `gh-pages` branch is written by edi's release workflow and served at
https://enhantica.github.io/edi-download/; the release files themselves are on [GitHub Releases](https://github.com/enhantica/edi/releases).
